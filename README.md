# 💼 Job Portal – Full Stack Recruitment Platform

A full-stack Job Portal web application that connects **Employers** and **Job Seekers** through a secure recruitment platform. The application streamlines the hiring process with role-based authentication, job posting, application management, resume uploads, and real-time application tracking.

---

- **Frontend:** https://jobportel-7f3p.vercel.app/
- **Backend API:** https://jobportel.onrender.com
- **GitHub Repository:** https://github.com/ragupathy-v/Jobportel

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/ragupathy-v/Jobportel.git

cd Jobportel
```

---

## Backend Setup

```bash
cd backend

python -m venv venv
```

### Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run Migrations

```bash
python manage.py migrate
```

Start Server

```bash
python manage.py runserver
```

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```
